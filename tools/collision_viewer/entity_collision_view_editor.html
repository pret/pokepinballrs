Notes

Normal files use angle = value & 0xFFF0 and type = value & 0x000F in little-endian u16 cells.

A filename with _WxH_typeless (for example catch_target_collision_48x48_typeless.bin) switches to one-byte cells: collision = value & 0x80, angle = (value & 0x7F) << 9. Typeless collision is displayed as type 3, but that type is fixed and not stored or editable.

Filename dimensions are read from a pattern like NAME_96x120.bin or NAME_48x48_typeless.bin.
