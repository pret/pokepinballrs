Notes

This page uses the masking pattern used for moving entities:
angle = value & 0xFFF0
type = value & 0x000F

The file size must equal width × height × 2 bytes for normal editing. Filename dimensions are read from a pattern like NAME_96x120.bin. If dimensions do not match the file, the page still loads but warns and only renders cells that exist in the file.
