# Pokémon Pinball: Ruby & Sapphire

This is a disassembly of Pokémon Pinball: Ruby & Sapphire.

It builds the following roms:

* pokepinballrs.gba `sha1: 9fec81ce2c5df589e0371a0bf2f92a5fe8db730b`
* pokepinballrs_eu.gba `sha1: b8b7881eaa9856b5ada99078ad1053d31cb79827` (European version, built with `make compare_eu`)

The European version (English, French, German, Italian and Spanish) is fully matching and all its code is C.
See [EUROPE.md](EUROPE.md) for what it changes, how the port is organized and what is left to do.

To set up the repository, see [INSTALL.md](INSTALL.md).
